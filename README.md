# Local Auto Subtitle Generator (本地端自動字幕生成器)

這是一個基於 Node.js 與 Whisper AI (`@xenova/transformers`) 開發的本地端自動字幕生成工具。支援直接將音訊或影片檔案拖曳至批次檔上，一鍵自動產生雙語（預設繁體中文與英文翻譯）SRT 字幕檔。

## ✨ 特色

*   **完全本機運行**：使用本地端 Whisper 模型進行語音辨識，無需依賴任何雲端付費 API（翻譯部分目前依賴 Google Translate API）。
*   **極簡操作 (Drag & Drop)**：免敲指令！直接把檔案拖曳到 `bat` 檔上即可開始轉檔。
*   **多格式支援**：內部整合 FFmpeg，支援常見音訊格式 (`.mp3`, `.wav`, `.m4a`, `.flac`, `.ogg` 等) 與影片格式。
*   **雙語輸出**：一次產生原始語言（辨識）與翻譯語言（繁體中文）的獨立 SRT 字幕檔。
*   **同資料夾輸出**：產生的字幕檔會自動與你的原始音訊檔放在同一個資料夾，保持檔案整理整潔。

## 🛠️ 環境需求

*   **Node.js**: 請確保你的電腦已安裝 [Node.js](https://nodejs.org/) (建議 v18 以上版本)。

## 📦 安裝步驟

1. 複製此專案到你的本機端：
   ```bash
   git clone <你的_repo_url>
   cd <資料夾名稱>
   ```

2. 安裝必要的相依套件：
   ```bash
   npm install
   ```
   *(註：初次執行程式時，會自動下載 Whisper AI 模型，需保持網路暢通且需稍微等待。)*

## 🚀 使用說明

有兩種主要的使用方式：

### 方法一：拖曳轉檔（🌟 推薦）
這是最方便的方法。
1. 直接把你想要產生字幕的音訊/影片檔（可一次選取多個）。
2. **拖曳到 `產生字幕_拖曳到我上面.bat` 這個檔案上面放開**。
3. 程式會開啟一個黑底白字的終端機視窗開始處理。
4. 處理完成後，程式會**自動在「你原本音訊檔所在的資料夾」產出同名的 `.srt` 字幕檔**。

### 方法二：掃描目錄轉檔
如果你有一大批檔案已經放在特定的資料夾內。
1. 將音訊檔放置在專案內的 `scripts/` 目錄下（或是你程式預設掃描的目錄）。
2. 直接**點擊兩下執行 `產生字幕_拖曳到我上面.bat`**。
3. 它會自動掃描目錄下所有的音訊檔，並把它們全部轉換成字幕。

## 📁 主要檔案結構

*   `scripts/generate_subtitles.js`: 核心的 Node.js 程式腳本，處理音訊轉換、Whisper 辨識、時間軸對齊與翻譯邏輯。
*   `產生字幕_拖曳到我上面.bat`: Windows 批次檔，負責接收拖曳的檔案路徑並傳遞給 Node.js 執行。
*   `package.json`: 專案設定檔與依賴套件清單。

## ⚠️ 注意事項

*   首次執行時，系統會自動下載 ONNX 格式的 Whisper 模型檔案（可能需要幾百 MB 空間），請耐心等候。
*   處理速度取決於你電腦的 CPU/GPU 效能以及音訊的長度。
